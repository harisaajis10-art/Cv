Tentang saya

Saya Haris Abdul Ajis, biasa dipanggil Ais. Saat ini saya menempuh pendidikan di jurusan Teknik Komputer dan Jaringan (TKJ) SMKN 1 Rancaekek.

Di luar kelas, saya mengerjakan proyek sendiri: menulis plugin untuk server Minecraft, mengutak-atik Linux dan Docker, serta membuat video sinematik dengan drone. Saya lebih nyaman bekerja tenang dan fokus, dan terbiasa menyelesaikan masalah dengan mencoba, membaca log, lalu memperbaikinya.
